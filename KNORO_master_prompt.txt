## 1. THE VISION

Turn-based kingdom strategy + city-building + diplomacy + tabletop-RPG on an isometric hex world. The player is the **Champion** who physically walks the map. Pillars: BUILD A KINGDOM · LIVE INSIDE THE KINGDOM · EVERY KINGDOM HAS A STORY · GEOGRAPHY CREATES POLITICS · DIPLOMACY MATTERS · THE MAP REMEMBERS. Design guides: `gameguide.txt`, `graphguide.txt` in the project root.

## 2. TECH STACK & LOCATIONS

- Godot **4.7.2**, GDScript, `gl_compatibility`. Default texture filter Nearest, MSAA 2D off. 1920×1080 canvas_items/expand.
- Owner machine: Windows 11, root `D:\Atolye\Game\` → `game\` (project), `engine\` (editor), `build\` (`KNORO.exe`, `KNORO_mac.zip` unsigned), `art_in\packs\` (original pack archives), `Play KNORO.bat`, `Open in Godot.bat`.
- Autoloads: `Style`, `Audio`, `Game` (`Game.state`, `changed`, `quest_done` signals), `Settings` (user://settings.cfg).

## 3. CODE ARCHITECTURE

Rules in `sim/` (no drawing, headless-testable), screens in `ui/`, renderers in `render/`.
- `sim/`: data.gd, hex.gd, world.gd (generation incl. dungeons), champion.gd, state.gd (all rules incl. quests + dungeon runs), battle.gd, save_game.gd (var_to_str dumps; slots auto/1/2/3 in user://saves).
- `render/`: map_view.gd (Tiny Swords hex world, 128-px hexes), ts_city.gd (pixel city), pixel_ui.gd (nine-slice panels/buttons, res icons, `backdrop()`, `on_dark()`), art.gd (pack backdrops), champion_token.gd, atmosphere.gd, shaders.
- `ui/` screens: title, story, select (real map preview in a SubViewport), create, world, city, dialogue, battle, dungeon, week, heir, end. Widgets: hud (incl. quest tracker), card + event_art (pack scenes), menus (pause/save/load/settings/help/credits), quest_log, inventory_panel, actor (battle sprites), item_icon, dice, fx.
- `core/main.gd`: screen manager (start screen = title), `menu_layer` CanvasLayer for modal menus, F11 fullscreen, debug args.
- Debug args after `--`: `--screen=title|story|world|city|dungeon:<id>|battle:<group>|dialogue:<id>|week|heir|end`, `--seed=N`, `--shot=x.png`, `--delay=s`, `--do="wait:1;key:x;click:x:y;call:fn:arg;rich;town;reveal;look:<place>;quests;pause;settings;help;saves:load;shot:path"`.
- `tools/`: ts_prepare.py (Tiny Swords copy/repack), packs_prepare.py (all other packs → assets/bg, units, props, icons), gen_audio.py.

## 4. CONTENT

- **Story / quests** (`data/quests.json`): main chain m1_banner → m2_ruins → m3_cave (Crystal cave) → m4_camp → m5_town → m6_crypt (Old crypt) → m7_fort (Sunken fort) → m8_city; reaching m8 shows the end screen (keep playing allowed). Side-quest pool offered at each week end (max 3 open). Objective types: build, place, res (deliver), item, dungeon, clear, age, kill, discover, pop, army, level. Rewards go to the kingdom.
- **Dungeons** (`data/dungeons.json`): rooms (fight/chest/trap/shrine/rest) + guardian; battle source `dungeon:<id>` returns to the dungeon screen. Groups: cave_bats, cave_rats, cave_slimes, kobold_den (boss), skeletons, zombies, crypt_lord (boss), gnoll_pack, pirates, crab_crew, troll_king (boss). Sim test: full band at Lv4 clears crystal 19/20, crypt ~12/20, fort ~6/20.
- **Events**: ~55 road events (`data/events.json`), art keys map to pack scenes in `ui/event_art.gd`.
- City: 29 buildings, level-3 branches, iron, storehouse items, Age III radius 5. Army 5 slots, Darkest-Dungeon battles. Boars renamed "Wild hogs" (Kings and Pigs pigs).
